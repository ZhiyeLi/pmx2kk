# v0.2.1 验证范围

这些结果来自发布前本地实际 KK 测试，不是仅根据 Blender 预览推断。发布仓库仅保留脱敏数值摘要；受模型再分发规约限制，不随仓库提供模型、贴图或转换产物，因此读者需自行获取资产复现。测试不证明任意 PMX 都可无人值守转换。

| 模型 | 最后一轮重建时间 | 游戏功能检查 |
|---|---:|---|
| 德丽莎 | 37.875 秒 | 眨眼、张嘴、脸型滑块、行走、整套换装、保存重载、彩色虹膜通过 |
| 女魔王 | 约 65.4 秒 | 同上 |
| 利维坦 | 约 51.6 秒 | 同上 |

计时为已有本地模板缓存的最后一轮重建，不包含首次安装、模板提取、人工调整和 KK 启动；其他硬件和模型可能更慢。不能把这些数字当作全流程时长保证。

面部验证覆盖正面与侧面特写；检查眼周/嘴周环状着色、腮部鼓起和接缝。数值回归包括：原生 UV 保持一致，原生 81 个表情通道保留，接缝重合点位移误差为零；表情相对形变误差约浮点精度量级。v0.2.0 已验收的身体适配、归一化和虹膜像素未改变。

新皮肤经过未压缩 DDS 导入，实际 Unity 格式为 ARGB32，1024 纹理含 11 级 mip，payload 为 5,592,404 字节。打包后的皮肤与源烘焙 PNG 的最大通道误差为 1/255；游戏内合成皮肤同样检查到最大 1/255。原先 DXT5 压缩可能造成可见色带，不能只比较 PNG。

本次发布仅增加文档、许可与可移植示例工具，转换核心沿用已验收 0.2.1。发布准备另外检查：Blender 4.5.0 插件注册/注销、Python 语法、示例哈希/材质校验与失败不写入、模板提取哈希、ZIP 成员范围、许可文件和敏感路径排除。脱敏数值见 [validation-summary.json](validation-summary.json)。
