# 故障排查

首先确认 Blender **4.5.0**、mmd_tools **4.5.13**、SB3Utility **24.3.3** 和原版 KK。保留失败任务的 `recipe.json`、`status.json` 和对应日志，先看首个异常。

| 现象 | 检查和处理 |
|---|---|
| 找不到 pmx2KK 面板 | 安装的是 Release 的插件 ZIP，启用后在 3D 视图按 N；GitHub Source code ZIP 不是插件安装包 |
| mmd_tools / OpenCC 导入失败 | 指向包含 `__init__.py` 的 mmd_tools 目录，并保留其 wheels；不要只复制一个 Python 文件或加载旧 CATS |
| SB3 DLL 加载失败 | 完整解压 SB3Utility 24.3.3，安装该工具要求的运行库；使用 64 位 Windows PowerShell；路径指向目录 |
| 缺少原版资源 | 检查游戏根目录和 SETUP 列出的 bundle；不支持 Sunshine，不要混入另一版本资源 |
| 缺少 Studio 模板、衣服粉色或材质异常 | 按 SETUP 获取验证模板；后端取首个 Material，必须是正确 Unity 版本及 shader；替代 bundle 需单独验证 |
| PMX 是粉色、贴图丢失 | 保持原包 PMX 与贴图相对目录，检查文件是否解压完整，重新检查；工作目录的 missing texture 提示有具体路径 |
| preset 哈希 / 材质不匹配 | 获取匹配版本，或手工分类；不要改 JSON 哈希强行套配置 |
| 分类改了但转换没变 | 从文件夹图标恢复 recipe，避免用旧面板覆盖新参数；预览副本改动不会自动回写配置 |
| 脸皮肤数量不正确 | 恰好一个 FACE；脸材质混合身体或多个脸材质需先在工作副本整理 |
| 头发 / 头饰错位 | 先检查 FACE / IRIS 分类和 `fit.json` 的虹膜选择；再细调 hair_scale / hair_offset；不要用光环最高点当头顶 |
| 瞳孔颜色丢失 | 必须使用生成卡 + 配套 zipmod，并安装 KK OverlayMods；只选择头型不带入卡内彩色眼贴图 |
| 眼圈 / 嘴圈出现色带 | 确认使用 0.2.1 新任务、新包，移除同 GUID 旧副本；皮肤应是 ARGB32，不能让下游工具又压成 DXT5 |
| 腮部鼓起或接缝突出 | 检查是否仍在加载旧包；降低 face_strength 并重建；复杂源脸或非标准朝向仍需手工适配 |
| 身体 / 脚趾扭曲 | 检查骨骼映射、PMX 的 D 骨/辅助骨和导入姿势；不能用缩放去掩盖错骨骼映射 |
| mesh 超过 65000 顶点 | 可开启“允许简化超大网格”后重建，或手工整理工作副本；检查手指、轮廓与权重，打包端仍会复查 |
| 长发像硬片 / 裙子不摆动 | 当前功能边界；STATIC 或短刘海模板不会自动移植 PMX 刚体与约束 |
| 载入卡出现额外后发 | 基础卡未替换的后发/侧发依赖仍在，先使用合适的空发型基础卡再生成；检查 card.json |
| 卡是普通图片 / 读不出 | 不能用图片软件重存或压缩人物卡；PNG 后附加的数据必须保留；使用 output 内原文件 |
| 卡缩略图和游戏里不同 | 初始缩略图来自 Blender；在 KK 保存后更新 |
| 改了导入比例后报错 | 必须重新“检查 PMX”，再分类；不要直接修改旧 source.blend 与 recipe 的比例 |

可以用新工作目录复现问题，保留原始模型和游戏文件。删除本插件生成的卡和 zipmod 后重启即可卸载相应转换结果；不要删除原版 bundle。重新安装源包前备份自己在 KK 修改的卡。

提交 Issue 时提供工具版本、失败阶段、报错文字、脱敏的参数与分类即可。日志和 recipe 含本机绝对路径，应先去掉个人目录信息。未经授权不要上传 PMX、贴图、游戏 bundle 或转换卡。对于特定模型问题，优先给作者原始配布链接和文件 SHA256。
